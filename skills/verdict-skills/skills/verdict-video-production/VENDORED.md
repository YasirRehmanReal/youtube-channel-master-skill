# Vendored: verdict-video-production

- **Source:** our own original work — the production rules for a faceless long-form channel, written in this project (Nov 2026).
- **Licence:** MIT (see repo root `LICENSE`). This component is ours; feel free to fork and adapt.
- **What it is:** `SKILL.md` — the hard rules learned the expensive way across real videos: 34–40 min target, measured voice pace (never assume 150 wpm), one consistent voice, free-tier quota discipline (10 requests/day/project, verify every narration part in full, discard defective parts, split parts that come back half-made), real footage first, images matched to the exact narration second, full-voice reference-clip islands (narrator silent), hard cuts with no whoosh, real music only, hook = trailer (first 1–5 min, cuts every 2–4s), never claim "perfect".
- **Kept/changed:** this copy is identical to the repo root `SKILL.md`. `skill.yaml` is included as-is (it contains project-specific measurement metadata).
- **Companion repos:** the edit tooling this skill routes to lives in the public `video-editing-skill` repo; the research skills live in the public `youtube-research-skill` repo.
